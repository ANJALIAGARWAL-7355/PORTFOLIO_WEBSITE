## ⚙️ Tech Stack
- **Frontend:** React 18, TypeScript, Three.js, React Three Fiber, GSAP, CSS3
- **Backend:** Python Flask, SQLite, RESTful API
- **AI/ML:** PyTorch, TensorFlow, Scikit-Learn, Transformers, LangChain, Pandas, NumPy

## 🚀 Running the Project

### 1. Frontend
```bash
npm install
npm run dev
```

### 2. Python Backend (Contact Form & SQLite Storage)
```bash
cd backend
python -m pip install -r requirements.txt
python app.py
```
Backend runs on `http://127.0.0.1:5000` and automatically persists submissions to `backend/contacts.db`.
